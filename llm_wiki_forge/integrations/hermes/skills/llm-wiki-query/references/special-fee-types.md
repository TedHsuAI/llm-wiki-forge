# 特殊車型加價費用類型

## 會加收額外費用的特殊需求

### ① 寶寶車組

- **加收金額**：從設定檔 `Fare4318` 讀取（固定金額）
- **觸發條件**：只要選擇寶寶車組就加收
- **尖峰離峰**：都收，不受尖峰影響
- **倍率**：正常乘倍率

### ② 節能減碳車組

- **加收金額**：從設定檔 `Fare4344` 讀取（固定金額）
- **觸發條件**：**只有尖峰時段才加收**，離峰不額外收費
- **倍率**：不乘倍率（費率固定為 1）
- 尖峰時 = 基本車資 + Fare4344
- 離峰時 = 基本車資（不加收）

### ③ 專派任務車組

- **加收金額**：根據「附近無人接單的車輛數」×「倍數」來計算
  - 公式：`FloorFareMultiple × ExceedFare4345`
  - 越多人沒接到單，加價越高
- **觸發條件**：選擇專派任務（優先叫車）就加收
- **倍率**：正常乘倍率

## 不會加收額外費用的特殊需求

以下這些是「派遣條件」，會影響司機要不要接單，但**不會影響價格**：

- 桃園送機（機場接送）
- 行李箱
- 攜帶寵物
- 微搬家
- 代接電
- 貴賓車
- 攜帶輪椅
